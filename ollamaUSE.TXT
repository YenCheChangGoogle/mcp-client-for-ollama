【ollama指令】

  ollama serve	運行 Ollama
  ollama create	建立自訂模型
  ollama show   例如: 觀看 qwen3:8b 模型資訊 ollama show  qwen3:8b

  ollama pull	抓取或下載指定模型到本機
  ollama push	上傳模型到 ollama hosting
  ollama list	列出本機模型列表
  ollama cp		複製現模型到指定namspace
  ollama rm 	移除模型
  ollama help

█ 【mcp-client-for-ollama】

範例 需要在PowerShell模式下 終端機互動模型(模型是llama3)
ollama run llama3
  
(1)使用此網址檢查ollama運作狀態(快速驗證ollama是否啟動的好方法) http://localhost:11434/api/tags
  
(2)取得mcp-client-for-ollama
   git clone https://github.com/jonigl/mcp-client-for-ollama.git
   cd mcp-client-for-ollama.git
 
(3)安裝虛擬環境 
   conda create -n ollama-client python=3.10 -y
   或 
   使用 --no-deps 減少依賴解析（如果你只需要 Python）
   conda create -n ollama-client python=3.10 --no-deps -y
  
(4)啟用虛擬環境
   conda activate ollama-client

(5)安裝pip
   conda install pip -y
   安裝pip並更新Conda
   conda update -n base -c defaults conda

(6)安裝MCP專案 (以管理者身分執行)
   cd C:\GIT\github\mcp-client-for-ollama.git
   python -m pip install .
   
(7)安裝後測試 MCP 是否成功
   ollmcp --help

(8)
   把目前的conda環境（包含所有套件與版本）匯出成一份內容到environment.yml檔案
   conda env export --name ollama-client > environment.yml
   
   當需要透過environment.yml重建環境時
   conda env create -f environment.yml


(9)ollmcp 相關指令 範例
   啟用 ollmcp 的自動補全功能 需要在PowerShell模式下
   
   ollmcp -a
   
   ollmcp --version
   ollmcp --install-completion
   ollmcp --show-completion
   
   
   
█ 一個簡潔的 Ollama GPU 啟動檢查腳本
  
  (C:\Docker\ollama\check_ollama_gpu.py)
  使用方式 python check_ollama_gpu.py 
  
  check_ollama_gpu.py 範例內容
  
  import os
  import subprocess
  import platform
  def check_nvidia_smi():
      try:
          result = subprocess.run(['nvidia-smi'], capture_output=True, text=True)
          if result.returncode == 0:
              print("✅ NVIDIA GPU 已偵測到")
              print(result.stdout.split('\n')[2])  # 顯示 GPU 型號
              return True
          else:
              print("❌ 無法執行 nvidia-smi，請確認 NVIDIA 驅動是否安裝")
              return False
      except FileNotFoundError:
          print("❌ 系統找不到 nvidia-smi，可能未安裝 NVIDIA 驅動")
          return False
  def check_ollama_version():
      try:
          result = subprocess.run(['ollama', '--version'], capture_output=True, text=True)
          if result.returncode == 0:
              print(f"✅ Ollama 版本：{result.stdout.strip()}")
              return True
          else:
              print("❌ 無法執行 ollama，請確認是否已安裝")
              return False
      except FileNotFoundError:
          print("❌ 系統找不到 ollama 指令")
          return False
  def check_env_vars():
      if 'OLLAMA_NO_GPU' in os.environ:
          print("⚠️ 環境變數 OLLAMA_NO_GPU=1 已設定，Ollama 將強制使用 CPU")
          return False
      print("✅ 未偵測到 GPU 禁用環境變數")
      return True
  def main():
      print("🔍 正在檢查 Ollama GPU 啟用狀態...\n")
      gpu_ok = check_nvidia_smi()
      ollama_ok = check_ollama_version()
      env_ok = check_env_vars()
  
      if gpu_ok and ollama_ok and env_ok:
          print("\n🎉 一切正常！Ollama 應該會自動使用 GPU 執行模型")
      else:
          print("\n🚧 請根據上方提示修正環境，以啟用 GPU 加速")
  if __name__ == "__main__":
      main()
  
█ 使用圖片模型 llama3.2-vision 來分析圖片 
  分析圖片的範例
  import requests
  import base64
  
  def analyze_image(image_path):
      with open(image_path, "rb") as image_file:
          encoded_image = base64.b64encode(image_file.read()).decode('utf-8')
      
      response = requests.post(
          "http://localhost:11434/api/generate",
          json={
              "model": "llama3.2-vision",
              "prompt": "Describe this image in detail",
              "images": [encoded_image]
          }
      )
      
      return response.json()["response"]
  
  print(analyze_image("test.jpg"))
  
  
█ 使用圖片模型 llama3.2-vision 來建立圖片分析入口
  來建立圖片分析入口的範例
  
  from flask import Flask, request, render_template
  import os
  
  app = Flask(__name__)
  
  @app.route('/', methods=['GET', 'POST'])
  def home():
      if request.method == 'POST':
          image = request.files['image']
          image_path = os.path.join('uploads', image.filename)
          image.save(image_path)
          
          analysis = analyze_image(image_path)
          return render_template('result.html', analysis=analysis)
      
      return render_template('upload.html')
  
  if __name__ == '__main__':
      app.run(host='0.0.0.0', port=5000)
